# materials/

**Primary sources of the course — your files are read-only for the agent.**

This is where the files **you** provide go: books (PDF), papers, slides, transcripts, video links, original notes from other sources, datasets, etc.

**Providing material is optional.** If you leave this folder empty, the agent teaches from its own knowledge and gathers sources itself **only when it needs them** (see `curated/` below and `AGENTS.md §4.1.1`).

## Rules

- **The agent NEVER modifies your files in this folder.** It only reads them.
- **The agent NEVER deletes files from here.** If something is surplus, you delete it.
- The agent only creates: indexes of your material (`TOC.md`, `links.md`) and, if you provided no material, the sources it gathers in `curated/`.
- If the material is a URL or something not downloadable, create a `links.md` here with the list.
- Clear and stable file names: if a PDF is called `Cracking the coding interview.pdf`, don't rename it mid-course — you'd break the references in `knowledge/`.

## What does NOT go here

- **Notes generated by the agent** → `knowledge/`
- **Session state** → `progress/`
- **User work (solutions)** → `progress/solutions/`

## Suggested structure

```
materials/
├── README.md                    ← this file
├── {{MATERIAL_FILE}}            ← core material (PDF or other)
├── TOC.md                       ← index of the core material (mandatory if PDF > 40 pp.)
├── links.md                     ← (optional) URLs, videos, online courses
├── extras/                      ← (optional) papers, cheatsheets, slides
└── curated/                     ← (only if you provided no material) sources gathered by the agent
    └── SOURCES.md               ← registry: one entry per source
```

## `curated/` — sources gathered by the agent

Used only when you didn't provide material. The agent fetches sources **just in time** (when its own knowledge isn't enough, exact wording or official data matter, or it needs real exercises/past exams) — never in bulk. Only reliable and legal sources (official docs, open textbooks, open-access papers); a file is downloaded only if its license allows it, otherwise only the link is kept.

`SOURCES.md` format:
```
## <title>
- URL: …
- Author / publisher: … · License: … · Accessed: YYYY-MM-DD
- Why: <what it was needed for> · Serves: block N / [[concept]]
- File: curated/<file> (if downloaded) · Used: <section / pages>
```

You can delete anything in `curated/` you don't want; the agent will fetch it again only if it needs it.

## Large PDFs — how to navigate them

The agent reads PDFs by page ranges (≈20 pages per read; if its harness can't read PDFs, it extracts text with a local tool such as `pdftotext`). For long materials:

1. **`TOC.md` is generated during setup** with chapter → page range.
2. The agent **checks `TOC.md` first** before deciding which pages to read — it never scans the PDF sequentially looking for something.
3. If a chapter exceeds 20 pages, it's read in 2-3 consecutive range reads.

Expected `TOC.md` format:
```
# TOC — {{MATERIAL_BASE}}
## Ch 1 — {title} · pp. 3-27
## Ch 2 — {title} · pp. 28-55
...
```

If the real PDF's TOC changes (new edition, reprint), tell the agent to regenerate `TOC.md`.
